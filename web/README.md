# Care-Bridge landing page

Static Next.js (App Router, Tailwind v4) landing page that links to the Telegram bot. No backend.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Set `NEXT_PUBLIC_TELEGRAM_URL` to the bot link (defaults to a placeholder in `app/page.tsx`).
`public/hero.mp4` is the hero background, edited so the figure is an older man.
