# Care-Bridge landing page

Static Next.js (App Router, Tailwind v4, shadcn/ui) landing page that links to the Telegram bot. No backend.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```

Set `NEXT_PUBLIC_TELEGRAM_URL` to the bot link (defaults to a placeholder in `components/site/telegram.tsx`).
Photos are from Pexels (`public/images`).
